OSM 開放地理資料庫學習導覽

什麼是 OpenStreetMap (OSM)?

OpenStreetMap（開放街圖）是全球最大的群眾協同創作地圖資料庫，常被譽為「地圖界的維基百科」。所有地理資料皆以開放資料授權 (ODbL) 提供公眾免費使用與加值應用。

圖磚 (Map Tiles) vs 原始地理資料

點陣圖磚 (Raster Tiles) 僅為已渲染完成的底圖圖片；而原始地理資料則包含 Node (點)、Way (線/面) 與詳細標籤 (Tags)，是 GIS 計算與搜尋的核心原料。

OSM 台灣切片與資料取得

包含 Planet.osm 全球備份、Geofabrik 每日區域切片檔 (PBF 格式)、Protomaps 即時向量切片，以及 Overpass API 即時 QL 查詢。

Overpass API 運作機制

Overpass API 是一個開放的唯讀 API，允許開發者使用 Overpass QL 語法查詢特定 bounding box 或行政區劃內的特定 key/value 屬性（例如：amenity=fuel、natural=peak），並回傳 JSON/GeoJSON 資料。
